<field_definitions>
document_relevance:
- "relevant" if at least one event is extracted.
- "not_relevant" if no event is extracted.

event_type:
- Must exactly match one allowed event_type value.
- If multiple labels seem possible, choose the most specific label directly supported by the grounding_quote.
- Remove the event if no allowed label is clearly supported.

location_text:
- Copy the place name that best anchors where the event happens.
- Prefer named places: countries, provinces, cities, districts, camps, border crossings.
- Do not use vague spatial or relational phrases such as "across the border", "nearby", "in the area", "outside the city", or "close to the coast" if a named place is available.
- For migration events, use the origin location for an origin crisis and the destination location for an arrival or influx event.
- If no explicit named event location is given, use "not_stated".

time_text:
- Copy the event-specific time expression exactly as written in the article.
- Examples: "on Tuesday", "in recent years", "this week", "since March", "during the rainy season".
- Do not convert to dates.
- Do not use publication metadata as event time.
- If no event-specific time is stated, use "not_stated".

time_status:
- "past" if the event clearly happened before the article's reporting moment and is completed or historical.
- "ongoing" if the event is continuing, current, rising, still happening, or affecting people at the time of reporting.
- "forecast" if the event is expected, projected, warned about, or likely to happen in the future.
- "not_stated" if the article does not provide enough information.
- Base this only on the article wording. Do not infer exact dates.

affected_entity:
- The thing, system, asset, or livelihood affected.
- Examples: "food and medicine", "healthcare system", "water supply", "maize crop", "roads", "aid supplies".
- If absent, use "not_stated".
- If this field does not make sense for the event, use "not_applicable".

affected_group:
- The people or population group affected.
- Examples: "farmers", "children", "refugees", "pastoralists", "Venezuelan migrants".
- If absent, use "not_stated".
- If this field does not make sense for the event, use "not_applicable".

severity:
- "low" for limited or mild impact.
- "medium" for meaningful but not severe impact.
- "high" for severe or large-scale impact.
- "extreme" for catastrophic, emergency, collapse-level, or massive impact.
- "not_stated" if severity cannot be grounded from the article.
- Base severity only on article wording and stated figures. Never infer severity from world knowledge.

modality:
- "asserted" if the article states the event as a fact.
- "reported" if the event is attributed to a source, authority, official, or organization.
- "projected" if the event is expected or projected in the future.
- "hedged" if the event is uncertain, possible, suspected, or conditional.

grounding_quote:
- Must be one exact, contiguous span copied from the article.
- Must be sufficient to justify the event_type.
- Prefer the shortest local quote that clearly supports the event.
- Do not paraphrase.
</field_definitions>
